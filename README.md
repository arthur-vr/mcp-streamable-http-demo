# mcp-streamable-http-demo

## setup

```
pnpm install
pnpm dev:server //localhost:3000
pnpm dev:client
```

## deploy on vercel

```
pnpm vercel:login // choose root directory /
pnpm vercel:dev
pnpm vercel:deploy
```
